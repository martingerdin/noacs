# noacs

R package to streamline data cleaning, analysis, and manuscript workflows for the [NOACS (No Accidents)](https://ki.se/en/research/research-areas-centres-and-networks/research-groups/health-systems-and-policy-cecilia-stalsby-lundborgs-research-group/no-accidents-improving-trauma-systems) research lab.

Designed to work across multiple trauma data sources (TITCO, TTRIS, TAFT, SweTrau, NTDB, and related local extracts) via a source-agnostic core and thin adapters.
